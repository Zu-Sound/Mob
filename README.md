## Mob - シンプルで軽快な音楽プレイヤー

■ 概要
Mob は、シンプルで軽快な操作性を追求した音楽再生アプリです。
再生機能に特化し、音楽をストレスなく楽しむための基本機能だけを
コンパクトにまとめています。

本ソフトは「実装型内部モデル方式」に基づいて構築されており、
再生処理をユニット化することで、軽量で直感的な操作性を実現しています。

■ 対応OS
Windows 10 / Windows 11（64bit）

■ 動作確認環境
Windows 11

■ 使い方

1. Mob を起動します。
2. 再生したい音楽ファイルを選択します。
3. 選択後、すぐに再生が始まります。

複雑な設定や操作は必要ありません。

■ インストール方法
Mob はインストールを必要としないポータブルアプリです。
ダウンロードした ZIP ファイルを任意の場所に展開し、
フォルダ内の「Mob.exe」を実行するだけで利用できます。

レジストリやシステム設定を変更しないため、
USB メモリなどに入れて持ち運ぶことも可能です。

■ アンインストール方法
Mob のフォルダを削除するだけでアンインストールが完了します。
レジストリやユーザーディレクトリに不要なデータは残りません。

■ 特徴
・シンプルで迷わない操作性  
・軽量で高速な動作  
・再生機能に特化したミニマル設計  
・余計な設定や画面を排除した構成

外部からの意図的な構築ではなく、

自然発生的に生じる秩序のことである。

この秩序は線形的な積み上げによって到達するものではなく、
構造が臨界点に達した際に突然顕在化する。

内的な動作原理が優先されるという前提に基づく。
ここでは UI は設計の結果ではなく、
内部構造の要請によって“滲み出る”現象として扱われる。

Mob の内部モデルは、標準コンポーネントの制約を

例えば一般には不可能とされる複数選択のドラッグ操作も、
標準 ListBox を用いたまま成立している。
これは特別な UI を作った結果ではなく、
内部世界の整合性が外部挙動として滲み出たものに過ぎない。

Mob における機能とは、追加されるものではなく、
成立を妨げる要素が取り除かれた後に
